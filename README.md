✦ Portfolio 02 | The Build Log
A minimalist, high-performance developer portfolio built with a "narrative" structure. This project tracks my technical evolution from a CS undergrad to a Full-Stack Developer through interactive storytelling and dark-mode aesthetics.

Live Demo →

Tech Stack
Framework: Next.js / React

Styling: Tailwind CSS (Dark Mode focused)

Language: TypeScript / JavaScript

Deployment: Vercel

Tools: Framer Motion (for dynamic hover effects), Git

Project Description
This portfolio is organized into "Arcs" to represent different stages of project development and skill acquisition. It prioritizes clean typography and a professional, minimalist aesthetic while showcasing both frontend design and backend logic.

01 Hero: Features a dynamic hover-reveal system that cycles through developer, designer, and problem-solver roles.

02 Ability Inventory: A categorized skill grid (S/A/B levels) showing mastery and current learning paths.

03 Featured Works: Highlights high-impact projects like GoldenBatch AI (Pharma ML Platform) and EchoHealth (Medication OCR MVP).

04 Experience Log: Documents virtual internships (Shadowfox) and national-level hackathon achievements (Top 10 at TechSprint IARE).
